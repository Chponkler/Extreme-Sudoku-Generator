# 🔢 Генератор Очень Сложных Судоку на Python

Этот проект — генератор **максимально сложных** Sudoku-головоломок, основанный на алгоритме бэктрекинга с проверкой **уникальности решения** и строгим контролем количества заполненных клеток.

## ⚙️ Как работает генерация

1. Создаётся пустая 9×9 сетка.
2. Вставляются **случайные 11 чисел**.
3. Судоку решается с помощью **бэктрекинга**.
4. Из решённой сетки удаляются числа до тех пор, пока:
   - не останется **17–22 подсказки**,
   - и решение остаётся **уникальным**.
5. Подсчитывается количество шагов, необходимых для решения — чем их больше, тем выше сложность.
6. Только сетки с **>300 шагов** сохраняются как «достаточно сложные».

- Стандартная библиотека (модули: `random`, `copy`, `time`)
